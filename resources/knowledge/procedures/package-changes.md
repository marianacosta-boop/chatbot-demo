
# Alteração de Pacote

## Upgrade

A mudança para um pacote superior pode ser feita a qualquer momento.

O comercial apresenta uma proposta com o valor proporcional ao tempo restante.

## Downgrade

A mudança para um pacote inferior só pode ser feita na renovação.

## Mudança para Standard

Se o cliente passar de Gold ou Premium para Standard, deve escolher uma modalidade semestral ou anual.

O Standard não tem modalidade mensal.

## Pedido de alteração

Para pedir uma alteração de pacote, o cliente deve contactar o comercial ou solicitar ao assistente que registe o pedido.

## Preços

Não calcular valores proporcionais.

Não inventar descontos ou condições.

Quando for necessário um valor comercial ou uma alteração contratual, encaminhar para o comercial ou para um humano.
